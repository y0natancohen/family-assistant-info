Privacy notice

This notice describes the private Family Assistant Calendar application. Contact the household owner through your existing private contact channel with questions or requests. The application is not open for public registration.

Access and use

With the account holder's consent, the application obtains Google Calendar read-only authorization. Google grants this scope for all calendars accessible to that account. The application restricts its calendar tool to one calendar selected by the owner. It reads event titles, times, locations, and status to answer calendar questions in an approved household chat.

Processing and sharing

The assistant runs on a privately operated home server. Event information used in an answer is sent to the configured AI provider, currently OpenAI, and replies are sent through WhatsApp, operated by Meta. Those services process data under their own terms and account settings. Do not place information in the selected calendar that you do not want processed through these services.

The application does not sell Google user data, use it for advertising, or use it to train a generalized AI model. The application owner's processing of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements. Provider-side handling remains subject to the selected providers' policies and account controls.

Storage and retention

OAuth credentials are stored in a protected keyring on the home server. Conversation state, local backups, and a bounded last-error diagnostic may retain calendar content until the owner deletes them. Access is restricted through the host and application permissions. No calendar content, account identifiers, or credentials are included in this public site or the application's GitHub source repository.

Control and deletion

The account holder can revoke the application's access from their Google Account third-party connections settings. Revocation prevents new Google API access but does not remove existing chat messages, conversation state, or backups. Ask the household owner to remove retained application data and backups. Chat and AI service copies are subject to those services' retention and deletion controls.
