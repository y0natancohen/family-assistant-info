Family Assistant Calendar

A private household assistant that answers calendar and email questions for its owner and approved family members. It is not offered as a public service.

Calendar and Gmail access is read-only. The assistant reads the calendars configured by the owner and, when separately authorized, searches and reads the selected Gmail account. It does not send email, change mailbox contents, or create, change, or delete calendar events.

Google's Calendar scope can read all calendars accessible to the authorized account. The assistant limits queries to the configured calendar list. The Gmail read-only scope can read the authorized mailbox; the assistant exposes on-demand message search, reading and selected attachment downloads. The owner can request saving document-derived household facts on the home server.

With separate consent, Google Drive provides a private document inbox and backup destination. Drive authorization can read the account’s Drive, while the assistant uses only the owner-selected folder. Write access is limited to files created or explicitly opened with this application. The assistant copies documents and household knowledge there and stores encrypted recovery snapshots.

Information and document pages retrieved to answer a request are processed by the configured AI provider. Replies are delivered through the approved household chat. See the privacy notice before authorizing access.
